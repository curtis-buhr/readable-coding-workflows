# Research and source licenses

The project uses these papers to frame questions and interpret results. The repository contains original summaries and synthetic benchmark artifacts. The project’s MIT license covers its original materials. Each cited work has separate terms.

| Cited version | What we used from the paper | Terms for that version |
| --- | --- | --- |
| Shi et al., [Natural Language Outlines for Code](https://arxiv.org/abs/2408.04820v4), v4 (2025) | Its human ratings help motivate short explanations aligned with meaningful code sections. The study addresses readability more directly than correctness across maintenance revisions. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Pan, Sun, Zhang, Lo, and Du, [Talking to Itself While Coding](https://arxiv.org/html/2609.09242v1), v1 (2026) | We distinguish asking an agent to write comments from supplying a correct comment as input. The reported generation effects varied by model and task. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Vitale, Guglielmi, Scalabrino, and Oliveto, [On the Impact of Code Comments for Automated Bug-Fixing](https://arxiv.org/html/2601.23059v1), v1 (2026) | The stronger repair results used descriptions derived from the fixed code. We use that distinction to frame a future experiment on accurate versus stale comments. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Hofmeister, Siegmund, and Holt, [Shorter Identifier Names Take Longer to Comprehend](https://doi.org/10.1109/SANER.2017.7884623), SANER (2017) | The C# study compares words, abbreviations, and letters. It motivates testing how much meaning a name conveys rather than treating length as a quality measure. | No public reuse grant verified for the [university-hosted copy](https://www.se.cs.uni-saarland.de/publications/docs/HoSeHo17.pdf). Citation and original summary only. |
| Shen, Xi, Du, and Li, [On the Lexical Superstition of Large Language Models for Code Comprehension](https://arxiv.org/html/2609.26388v1), v1 (2026) | Renaming variables while preserving behavior suggests a way to isolate identifier effects in a future C# experiment. | [arXiv non-exclusive distribution license](https://arxiv.org/licenses/nonexclusive-distrib/1.0/license.html). The grant covers arXiv’s distribution. |
| Gloaguen, Mündler-Sasahara, Müller, Raychev, and Vechev, [Evaluating AGENTS.md](https://arxiv.org/html/2602.11988v3), v3 (2026) | The behavioral and cost effects motivate measuring whether agents follow the instructions and what the added work costs. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Shepard and Albrecht, [Probe-and-Refine Tuning of Repository Guidance for Coding Agents](https://arxiv.org/html/2606.20512v2), v2 (2026) | Its failure-driven instruction tuning suggests a separate experiment with tuning tasks and a frozen evaluation set. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

The repository links to these versions and credits their authors. Paper PDFs, figures, tables, datasets, replication code, and prompt text are kept at their source.
